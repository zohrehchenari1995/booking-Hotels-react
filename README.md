
# 🏨 Hotel Booking Web App

A modern hotel booking application that allows users to search, explore, and save hotels based on destination and room preferences. The app provides an intuitive UI with filtering options, map-based selection, and detailed hotel pages.

---

## ✨ Features

### 🏠 Home Page
- Displays a list of all available hotels
- Clean and responsive layout for easy browsing

### 🔍 Smart Search System
- Search hotels by **destination**
- Filter results by:
  - Number of rooms
  - Number of adults and children (UI-based, backend-limited usage)
- Search button dynamically fetches matching hotels

> Note: Due to backend limitations, date range (check-in/check-out) and guest filters are partially UI-driven and primarily used for display.

---

### 📅 Calendar & Filters (Header)
- Interactive calendar for selecting:
  - Check-in date
  - Check-out date
- Dropdown filters for:
  - Rooms
  - Adults
  - Children
- Combined search experience for better user control

---

### 🏨 Hotel Details Page
- Click on any hotel to view full details
- Displays only selected hotel information
- Clean dedicated page for better focus

---

### 🗺️ Map Integration
- Select location directly from the map
- Add chosen locations to the booking list
- Improves visual and geographic selection experience

---

### 📌 Booking List
- Add selected hotels/locations to your booking list
- Remove any item anytime
- Simple and user-friendly management system

---

## ⚙️ Tech Stack
- React (Vite)
- JavaScript (ES6+)
- CSS / Responsive Design
- REST API (Backend Integration)
- Map Library (e.g. Leaflet or similar)

---

## 🚀 How It Works

1. Open the home page and browse hotels  
2. Use the search bar to filter by destination and rooms  
3. Optionally adjust room/guest filters  
4. Click **Search** to view results  
5. Select a hotel to view details  
6. Use the map to pick locations and add to booking list  
7. Manage your saved bookings easily
